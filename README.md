# PRODIGY_DS_05

## Traffic Accident Data Analysis and Visualization

This project focuses on analyzing traffic accident data to identify patterns related to weather conditions, road conditions, crash timing, injury severity, and contributing factors. The analysis was performed using Python with powerful data visualization techniques to uncover accident trends and hotspots.

---

## 📊 Project Objectives

- Analyze traffic accident patterns
- Identify factors contributing to accidents
- Study the impact of weather and road conditions
- Examine accident frequency by hour and day
- Visualize injury severity and crash distribution
- Create heatmaps and colorful visualizations for better insights

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📈 Visualizations Included

- Accidents by Hour of Day
- Weather Condition Analysis
- Road Surface Condition Analysis
- Traffic Control Device Analysis
- Crash Type Distribution
- Injury Severity Distribution
- Heatmaps for Crash Frequency
- Correlation Heatmaps
- Weather vs Injury Severity Analysis
- Road Defect Contribution Analysis

---

## 🔍 Key Insights

- Most accidents occur during peak traffic hours
- Weather and road surface conditions significantly affect accident frequency
- Certain crash types are more common than others
- Injury severity varies based on environmental and traffic conditions
- Heatmaps reveal accident hotspots across different times and conditions
